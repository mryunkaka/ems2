# Radiology reference images

`fracatlas-leg-fracture-frontal-img0002320.jpg` is an unchanged reference
image from FracAtlas (`IMG0002320.jpg`). FracAtlas is the dataset described by
Iftekharul Abedeen, Md. Ashiqur Rahman, Fatema Zohra Prottyasha, Tasnim Ahmed,
Tareque Mohmud Chowdhury, and Swakkhar Shatabda, “FracAtlas: A Dataset for Fracture
Classification, Localization and Segmentation of Musculoskeletal Radiographs,”
[Scientific Data 10, 521 (2023)](https://doi.org/10.1038/s41597-023-02432-4).
Dataset record: [Figshare article 22363012](https://doi.org/10.6084/m9.figshare.22363012).
The dataset is published under the [Creative Commons Attribution 4.0
International license](https://creativecommons.org/licenses/by/4.0/).

This curated sample is selected only for `Tibia-Fibula` fracture cases with
an AP request. Its CSV metadata supports only the broad labels `leg`,
`fractured`, and `frontal`; it does not reliably identify the precise bone,
side, fracture level, age, or AP versus PA. The image is therefore shown in a
separate, explicitly attributed reference card and must not be presented as
the current patient's radiograph or used to populate the case findings.

The source image is kept unchanged. FracAtlas authors are not affiliated with
or endorsing this application.
